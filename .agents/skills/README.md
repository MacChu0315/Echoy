# Mosaico 工程技能

6 项任务相关的工程指南，全部 9 项技能见[统一入口](../../README.md)，3 项体验与设计试用技能见[试用分组](../../skills/README.md)。按需读取，不要求全套执行。

| 技能 | 适用任务 |
| --- | --- |
| [mosaico-gsp-parity](mosaico-gsp-parity/SKILL.md) | 认可原型到共享 C/GSP，实际回调、截图提交与资产一致性 |
| [mosaico-runtime-performance](mosaico-runtime-performance/SKILL.md) | 任务等待、帧率、精确缓存、内部 RAM／PSRAM |
| [mosaico-realtime-input](mosaico-realtime-input/SKILL.md) | 完整新样本、源状态所有权、时效、真实数组回放与角色时序 |
| [mosaico-peer-cooperation](mosaico-peer-cooperation/SKILL.md) | 物理接触、通信、成员、时钟和权限实现 |
| [mosaico-audio-validation](mosaico-audio-validation/SKILL.md) | 参考算法、实际 PCM、实体声音 |
| [mosaico-release-evidence](mosaico-release-evidence/SKILL.md) | 产物／运行身份、官方更新、审阅包与实际验收范围 |

既有设计认可和有效授权继续适用；这些技能不新增逐项审批，也不授予操作其他设备、远程仓库或录音的权限。操作命令和版本由目标工程维护。

可以独立复制完整技能目录及许可来源，或使用固定 submodule 的目录链接。参考文件保留在技能内。不会自动安装全局技能或启用试用分组。原 [历史验证](VALIDATION.md) 保留；当前变化与检查见[本轮验证](../../docs/VALIDATION.md)。
