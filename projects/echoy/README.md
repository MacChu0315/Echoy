# Echoy GSP application

The native simulator and firmware share `main/echoy_ui.c`, `echoy_model.c`,
`echoy_music.c`, `echoy_art.c`, `echoy_art_image.c`, and the GSP scene/resources.
Four roles and twelve expressions use the frozen prototype's composition rules.
Home, role, settings, guide, information and recovery pages support Chinese/English.

From the repository root, follow [the workspace instructions](../../README.md).
`ui/main.json`, the page contract, view keys and icon/font assets are generated by
`../../tools/generate_scene.py`; edit the generator, then regenerate.
The retained Vibe Mode integration and `main/board_display.c` use the official template.

The two home drawings use continuous Canvas callbacks. The three gallery drawings
use runtime QOI images generated by the same C renderer, keeping within the official
simulator's two Canvas slots. COPY submission owns its bytes immediately; completion
is tracked separately and UI teardown never frees a pending callback context.

`pc/platform_pc.c` supplies monotonic time, optional local controls and real plan JSON
export. The approved simulated remove action appears only on PC. Audio synthesis,
wireless multi-device operation and real battery/peripheral data remain unfinished.
Do not install this as a finished musical application; no hardware acceptance is claimed.
