# 本轮有限情景检查

主题与输入见 [cases.json](cases.json)，原始返回见 [基线](baseline.md) 和 [读取技能后](with-skills.md)。两个会话使用 `fork_turns=none`，没有给出作者的答案或评分条件；基线禁止读技能，有技能组只能按需读取相关 SKILL.md 和自身参考。两者均未执行工程修改、设备操作或网络写入。

每组只有一次、每次同时回答五题；输入围绕同一主题但并非逐字相同，尤其 D 的基线描述含“软件成功更新但终端超时”，有技能组只说终端超时。这不是严格对照实验，也不证明普遍改进。执行器未提供确切模型版本；保留这项复现限制。
